# 阶段 D：体验与完整亮点

## 本阶段做了什么

- **编辑**：详情页「编辑」→ 复用 AddItem 表单，带 `itemId` 预填 → `updateItem`
- **删除**：详情页「删除」→ `Alert.alert` 二次确认 → `deleteItem`
- **置顶 / 取消置顶**：详情页切换 `isPinned`，首页「置顶」分区展示
- **最近添加**：按 `createdAt` 降序，最多 3 条（不与置顶重复）
- **完整空状态 L7**：无数据时引导文案 + 按钮直达添加页
- 列表分区：置顶 → 最近添加 → 全部物品

**达成亮点**：**L6** 最近/置顶 · **L7** 空状态引导 · **L8** 编辑删除确认

---

## 核心交互

| 操作 | 入口 | 行为 |
|------|------|------|
| 置顶 | 详情页 | togglePin，首页置顶区刷新 |
| 编辑 | 详情页 | navigate AddItem { itemId } |
| 删除 | 详情页 | Alert 确认后 goBack |
| 空状态 | 首页无数据 | EmptyState → AddItem |

---

## 自测步骤

1. 详情 → 置顶 → 首页「置顶」区出现
2. 详情 → 编辑改位置 → 保存 → 列表与详情同步
3. 详情 → 删除 → 取消 / 确认 各测一次
4. 演示页清空全部 → 空状态 → 点添加

---

## 答辩小问题

**Q1：为什么删除要二次确认？**  
A：防误触；本地删除不可恢复，属于体验亮点 L8。

**Q2：最近添加为什么 limit 3？**  
A：首页信息密度；答辩够演示即可，可改常量 `RECENT_LIMIT`。

**Q3：编辑为什么复用 AddItem 而不是单独 EditScreen？**  
A：表单字段相同，DRY；通过 `route.params.itemId` 区分模式。
