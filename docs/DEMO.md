# 宿舍物证库 — 3 分钟答辩演示脚本

> 建议真机演示。答辩前在「演示与数据」页导入演示数据，或保留自己拍摄的 3～5 条。

---

## 0:00 — 开场（15 秒）

「这是 **物证库**，解决宿舍东西放哪就忘了的问题。给物品拍一张照，记下位置，以后搜一下就能找到。数据全部在手机本地，不上传。」

---

## 0:15 — L1 建档 + L4 详情（45 秒）

1. 点右下角 **+**
2. 「可以 **拍照** 或从 **相册** 选图」→ 选一张
3. 填：**氮化镓充电器** / **书桌右侧抽屉** / 备注可选
4. 点标签 **数码**、**线材** → **保存物证**
5. 点刚创建的卡片 → 「详情页有 **大图**、位置、**备注** 和标签」

---

## 1:00 — L3 搜索 + L2 标签（30 秒）

1. 返回首页，搜索框输入 **充电**
2. 「只显示名称、位置或标签里带充电的物品」
3. 清空搜索，点标签 **证件**
4. 「按标签 **筛选**，再点全部取消」

---

## 1:30 — L6 置顶 + 最近（30 秒）

1. 进入 **校园一卡通** 详情 → 点 **置顶**
2. 返回首页 → 「置顶区会固定显示常用物品」
3. 「**最近添加** 按时间排序，方便看刚记的东西」

---

## 2:00 — L8 编辑删除（30 秒）

1. 任选一条 → **编辑** → 改位置 → 保存
2. 「编辑复用同一套表单」
3. 点 **删除** → 「有 **二次确认**，防误删」→ 点取消（或删一条演示）

---

## 2:30 — L5 持久化 + L7 空状态（30 秒）

**L5（口播 + 可选录屏）**  
「所有数据存在 AsyncStorage，关掉 App 再开还在。我提前录了屏 / 你们可以看我杀进程再打开。」

**L7（可选，时间够再做）**  
「演示页 → 清空全部 → 首页会出现 **空状态引导**，告诉用户第一步做什么。」

---

## 2:50 — 收尾（10 秒）

「8 个亮点：建档、标签、搜索、详情、持久化、置顶最近、空状态、编辑删除。技术栈 React Native，纯本地离线。」

---

## 可能被问到的问题

| 问题 | 回答要点 |
|------|----------|
| 为什么不用 Web？ | 要相机、随身、离线 |
| 数据安全？ | 不出设备，无账号 |
| 和备忘录区别？ | 以照片为主，专找东西 |
| 图片会丢吗？ | URI 引用；演示用刚拍的图；可扩展复制到应用目录 |
